# 二手物品估值研究

个人私有研究仓库：策略性缺失、预算核验、估值算法与三区论文。

先读 [START_HERE.md](START_HERE.md)，它集中记录AI接手说明、研究目标、实现状态、创新边界和数据入口。

[完整研究源码包](secondhand-valuation-research-source.zip) 包含309个文件：实验/审计源码、配置、测试、论文LaTeX、设计与复现协议、机器可读状态和小型证据。解压后请先阅读包内 README.md 与 AI_HANDOFF.md。

当前30/30训练评估组合、4320个单元已完成；独立审计仍在进行。本仓库是有时间戳的快照，不是实时监控。约24GB本地模型与逐条输出不在包内，公共数据DOI与获取边界见 START_HERE。
