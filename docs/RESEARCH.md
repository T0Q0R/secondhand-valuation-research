# 想法、目标与创新边界

## 问题

公开缺失无法直接区分自然缺失和策略隐瞒。有限核验预算使同批卖家的查询机会竞争；一个卖家更换报告可能改变全批分配。仅按独立加性 top-B 分数选取不自动等于真实激励最优。

## 已实现的候选贡献

- 可观测报告预算 oracle：在相同信息约束下比较最优值与候选规则库；特权恢复性 oracle 不是可部署方法。
- 精度—激励前沿：均匀诚实误差与核验中性条件下，给出预算与抑制偏离的边界；平均 MAE 不能替代均匀界。
- 紧凑边际与受限固定混合分离：字段级边际避免枚举所有分配；但上下文策略库可闭合所示分离，不宣称LP本身的新优势。
- 核验历史 cap：逐个实现结果取核验前后报价较小值；在固定同伴、诚实中性条件下弱化单边收益，不能保证MAE或重算后的均衡改善。
- 条件概率稳定性：固定查询字段、正分数下界时有概率扰动界；字段切换、近零分数和适应性同伴是边界。
- 匹配因子审计：把初始估值目标、acquisition、feedback、allocation分开，解释收益或失败来自哪个环节。

随机化、LP、water filling、min cap、策略性缺失和部分核验均有前人工作。候选创新需要逐项对照文献，不可声称这些基础工具首创。论文增补稿包含具体理论、引用、反例与证据。

## 评价与统计

主指标 positive expected log inflation 比较方法自身的攻击/诚实报价，不是相对真实成交价值。诚实MAE、攻击期望MAE、失败核验、deviation envelope、regret和随机实现正膨胀须一起报告。期望绝对误差必须先分别计算随机端点误差，不能对期望报价取绝对误差代替。

区间为固定队列下跨训练种子×共享批次的探索性重采样，不能解释成独立挂牌重复样本或新确认实验。正的反馈×分配交互并不代表两者都有益。所有预定对比和未收敛响应须保留。

## 论文方向

以明确条件的理论边界、可审计实现与异质性机制为核心；保持负结果。既不强行宣称普遍更强，也不放弃真实创新。
