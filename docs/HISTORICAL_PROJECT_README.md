This research studies advertised used-vehicle prices when simulated sellers
can withhold recorded attributes. A query replays a recorded value; it is not
a physical inspection. Historical validation cohorts remain retrospective
research evidence. Source prices are asking prices, not transaction values.

SAV-Val combines a mask-aware estimator, learned suppression-value queries
and policy-aware residual training. CDM-Val fixes the price estimator and
optimizes a distribution over complete hard-cap verification rules against
finite counterfactual unilateral-deviation rows. Sellers lock reports before
the private rule draw. Neither candidate establishes universal superiority
or universal incentive compatibility.

The corrected main contract is `plan/protocol-v2.md`; the original comparison
is recorded in `plan/protocol.md`. Historical v1 deployability claims are
withdrawn because query eligibility used private simulation masks. See

fields; unsuccessful queries consume capacity.
