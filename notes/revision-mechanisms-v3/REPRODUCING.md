# Reproducing this incremental revision

Extract paper/revision-delivery-v3.zip at the sav-val project root. It contains current source/PDF, v3 diagnostics/code/paired differences, explicit audit protocol and six directly bound evidence artifacts. It does not contain raw listings or trained weights. The older revision-delivery-v2.zip and separate full-expanded-evidence.zip remain independently indexed historical/supporting bundles; their manuscript is superseded.

1. `python3 audit-protocol/validate_protocol.py --self-test` validates the post-hoc contract and the six direct artifact bindings using only the standard library. It does not re-run training or verify transitive input hashes.
2. `diagnose.py` replays variance and cost diagnostics from original local inputs listed in completion.json, requiring NumPy/pandas and the original saved state files for zero-cost counts. paired_differences.npz and the formula in DIAGNOSTICS.md permit conditional variance reanalysis without original models/records. Existing cost summaries do not identify exact positive-cost concealment states.
3. `final_record_pilot.py` additionally requires the original validation files, frozen joblib models and original scientific Python environment. Its receipt binds each. No model fitting occurs. Runtime with two math threads was a few seconds on the original machine; that is not an external-machine reproduction claim.
4. `revise_manuscript.py` reads its byte-bound reviewed baseline and existing numerical artifacts, then writes the current source in place. It must not be replaced by the older v2 generator, which would erase this revision. It does not export a PDF or certify compilation. Source backfill resets its compile/QA status until checks run.
5. Compile current paper/innovation-addendum-v1.tex with the desktop built-in compiler and export the same document with XeTeX/Tectonic when layout verification is needed. audit_render.py renders/checks reference/page-boundary facts; its visual status remains pending until inspected by a human or visual agent. The delivered receipt records the completed inspection.

No new data access permission, public license, DOI or author approval is implied by the bundle. Source-specific currency and shared-support/abstention definitions must remain attached to the final-record MAEs. These post-hoc results do not establish equivalence or confirmatory error coverage.
