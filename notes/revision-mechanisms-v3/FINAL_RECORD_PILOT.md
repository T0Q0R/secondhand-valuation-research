# Final-record categorical envelope: restricted empirical pilot

Command: `OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 ../.venv-gdfs/bin/python notes/revision-mechanisms-v3/final_record_pilot.py`.

This post-hoc illustration uses robust/no-feedback deployment models with seeds 13, 42, 2026, and the original first 1,000 validation records of each real source. No model is trained or tuned; no response optimization is performed. For each seed, the three categorical action fields use their frozen training-encoder vocabulary, including the missing token. All combinations extending the honest observed categories are enumerated; absent categories may remain absent. Mileage must be observed and remains fixed. Other features are fixed. Observed category values outside the declared vocabulary and missing-mileage records abstain. Coverage is reported before errors. The domain is frozen from training, never chosen with validation targets.

JUCars covers 801/1,000; 199 abstain for missing mileage. Only one covered record has a missing category. MUCars covers 999/1,000; one abstains for missing mileage, and 28 covered records have a missing category. Each model evaluates 806 JU and 1,139 MU completions. These small natural-missingness subsets limit what can be learned from aggregate MAE. No unqualified full-cohort MAE is reported.

The envelope includes the current record. Singleton completion sets use the original quote exactly; current quotes are explicitly included in minima to avoid batch-size floating-point artifacts. A direct one-record quote path is cross-checked against the production all-state prediction route on sampled completions (including a minimum); all original honest quotes are checked against saved predictions with tolerance 5e-6 in log quote. Numerical residuals and hash-bound model/data provenance are in final_record_completion.json. Model inference primitives are shared; this is not a from-scratch model audit.

The corresponding incentive argument is limited to concealing those categorical fields while keeping mileage and other features fixed, and to truthful values covered by the declared vocabulary. It gives no guarantee for mileage concealment, unseen categories, unbounded continuous completions, new populations or the full original four-field game. It does not establish a deployable replacement for the history cap. The empirical cost may be lower or higher MAE: predictions are reduced, absolute error need not increase. Per-seed shared-support MAE, signed error and quote reductions are retained, including the missing-category subset. Results do not supply uncertainty bands or an equivalence claim.

The first run stopped on a read-only NumPy eligibility view before inference results were saved; the source now explicitly copies the array. The final completed run is bound by its script hash. No failed experiment is reported as completed.
