# 近期基线扩充至五个：冻结实验方案

2026-10-15，用户明确要求近期基线做到5个。方法计数为ACO2024、SEFA2025、GDFS2023、DIME2024、解释驱动AFA2025；不同种子/参数/估价后端不重复计为方法。ACO已有144个单元；SEFA已有独立队列108个单元。此次新增后三者，各108，共324个评估单元。正式结果尚未产生。

## 来源与方法身份

- GDFS：Learning to Maximize Mutual Information for Dynamic Feature Selection，ICML2023，https://proceedings.mlr.press/v202/covert23a.html ，原作者仓库https://github.com/iancovert/dynamic-selection 。使用SEFA公开比较代码中的GDFS网络实现；保留可微RelaxedOneHot选择、温度退火和预测交叉熵。**这是来源明确的任务适配，不是原作者代码原样复现。**
- DIME：Estimating Conditional Mutual Information for Dynamic Feature Selection，ICLR2024，https://arxiv.org/abs/2306.03301 ，原作者仓库https://github.com/suinleelab/DIME 。使用SEFA比较实现，保留熵缩放价值网络、epsilon贪心和实际交叉熵下降回归。
- 解释驱动AFA：Active feature acquisition via explainability-driven ranking，ICML2025，https://proceedings.mlr.press/v267/guney25a.html ，官方仓库https://github.com/vkola-lab/icml2025 。直接使用官方GPT和MLP类，保留TreeSHAP排序监督→策略生成轨迹二阶段。仅从官方训练文件提取MLP类，避免执行原数据下载、CLI或外部日志。
- 源码固定提交与逐文件哈希见SOURCES.json。保留MIT许可；不上传官方示例患者/车辆数据或无关文件。

## 适配边界：必须随结果一起报告

1. 采用训练分位数得到4个价格类别训练采集策略，最终价格预测仍由原masking/static-robust回归后端给出。不是声称这些分类策略原生解决了价格回归。
2. 已公开的非查询字段作为上下文；训练从均匀抽取的合法报告开始，最多隐藏2个原本可见字段，最多训练2步恢复。不同于原始从空记录开始、任意长采集轨迹。天然缺失不可恢复；训练可用自然缺失标签，部署评分只能看到公开缺失，不知缺失原因。
3. 部署最多查询一个字段，统一top-B共享批次容量；GDFS/解释AFA的策略概率与DIME的信息分数作为跨记录分配代理，**未经证明跨记录可比**。两种固定估价后端只能隔离一部分因素，不能把全部差异归因于算法名称。
4. GDFS/DIME沿用SEFA官方比较配置1/5/9（每个方法3试验），预训练80轮、每退火阶段15轮；不冒称使用原作者全部超参搜索或原优化器日程。此次使用Adam、阶段间加载最佳训练内验证模型，未使用原ReduceLROnPlateau调度。
5. 解释AFA采用官方小表格网络规模（隐藏128、嵌入64、3层4头GPT、最多4步上下文），250轮预训练+200轮排序监督+16轮策略轨迹；3个学习率0.001/0.0005/0.0003训练内选择。前两项在官方脚本出现，第三项是预先固定的局部敏感性值，非原论文默认。训练仅需2步上下文，部署无历史时使用固定初始动作标记，不把真实隐藏字段作为历史。
6. 解释AFA的TreeSHAP教师是本拟合分区训练的250树CatBoost四分类器；对目标类别取各字段值和缺失指示贡献绝对值之和。原仓库提供预计算SHAP，不包含我们的数据教师；这一教师生成、数值化分类字段和天然缺失处理均为明确适配。SHAP仅用于训练监督，验证/评测不输入SHAP或真实标签。
7. 所有新增方法使用相同80:20训练内划分、3个试验，以查询前后平均分类NLL选择配置；再在完整训练数据上按该配置全部轮数重拟合，输出最后检查点。训练内验证不能覆盖训练人口不确定性。3种子为开发证据，不能自动升级为确认性结论。

## 数据、指标与验收

3来源×3种子(13/42/2026)×2固定价格后端×6预算(0,.01,.05,.1,.2,.3)=108/方法；三个方法共324。每来源/种子/方法3试验+1全训练重拟合，共108次策略拟合；解释方法的额外教师拟合另记，不是新增价格后端拟合。

完整保留honest/attacked MAE、positive log inflation、failed query、bias和响应后悔/不收敛率。不得仅按inflation判断获胜，不丢弃非收敛单元。各单元输出独立整数状态/分配/合法偏离收益复算凭据。小测只证明可执行和接口正确，不作为论文结果。

零查询应与对应冻结价格模型一致；隐藏数值扰动不应改变对应公开状态采集评分；后端模型、评测数据和结果哈希均绑定。额外实际结果汇总与seed配对差异脚本随队列执行，图表与科学解释另行审核。
