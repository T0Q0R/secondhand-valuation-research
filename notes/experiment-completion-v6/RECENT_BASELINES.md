# Primary-source baseline eligibility scan,2026-10-14

Status is eligibility review, not completed execution. Do not claim these new baselines ran.

| Candidate | Primary paper / official code | Initial compatibility boundary |
|---|---|---|
| GDFS/DIME2023 | https://proceedings.mlr.press/v202/covert23a.html ; https://github.com/iancovert/dynamic-selection | Dynamic information-maximizing selection, grouped input support in official examples; original experiments classification. Verify regression loss/general-policy code, public reported-state input and hard batch allocation adaptation. |
| ACO2024 | https://proceedings.mlr.press/v235/valancius24a.html | Already144local-adaptation cells in original project. Do not relabel as an unchanged official sequential execution. |
| SEFA2025 | https://proceedings.mlr.press/v267/norcliffe25a.html ; https://github.com/a-norcliffe/SEFA | Official MIT code. Latent sampling/gradient scores in original class-conditioned description. Need inspect regression/mixed categorical support before selecting implementation. |
| Explainability-driven AFA2025 | https://proceedings.mlr.press/v267/guney25a.html | Policy/feature-ranking approach. Official paper/software must be inspected before deciding whether a regression adaptation is faithful and resource-comparable. |
| L2M2025/v2May2026 | https://arxiv.org/abs/2510.12624v2 ; https://github.com/reAIM-Lab/Learning-To-Measure | Meta-task/in-context prior differs from fixed-cohort price regression. Check pretrained checkpoint, training-data overlap, continuous-label support and local CPU feasibility. Do not call a changed label-discretization proxy the original method. |

The2025SEFA paper's official supplementary comparisons include EDDI, GDFS and DIME, providing a source-grounded relevance chain. Classical SMI2020 regression and IC-LR2021 classification have different task interfaces; the latter's theoretical relevance alone does not make it a numeric price comparator. Literature inclusion, method eligibility, implementation, completed fitting and audited evaluation are separate statuses.
