# 处理决定：保留证据，限定结论，继续原审计

已从原六单元摘要重新计算同机器内λ=1相对λ=0的匹配效应。只涉及synthetic、seed13、固定1000条评估记录和10个共享批次。32次诊断重放没有增加独立拟合种子数；没有计算p值或置信区间。

## 已核验的实际影响

主容量10%的描述性结果：

| 指标（λ=1相对λ=0） | 本机 | 外机 |
| --- | ---: | ---: |
| mean positive log inflation降幅 | 53.97% | 57.54% |
| honest MAE增幅 | 0.83% | 0.94% |
| attacked MAE变化 | -1.47% | -1.69% |
| failed query增幅 | +1.10个百分点 | +1.40个百分点 |
| 固定peer单边inflation包络降幅 | 53.97% | 57.39% |
| λ=1最大剩余单边后悔值 | 0.0002041 | 0.0219727 |
| λ=1未收敛批次 | 1/10 | 1/10 |

三档容量下，inflation下降、honest MAE略增、attacked MAE下降的方向均未反转。正预算下失败查询均上升。固定peer单边包络也保留inflation下降的方向，但该包络只覆盖每个卖方固定他人报告后的单边偏离，不覆盖任意联合变动或所有均衡。

最坏单边后悔值明显不同；30%容量下，λ=1的未收敛批由本机1/10变为外机2/10。不能因平均MAE差异较小而把所有跨机变化称为无关紧要，也不能据此宣称激励保证、全目标优势或总体跨平台等价。

CSV还报告原研究10% inflation/5% honest-MAE筛选门槛的事后描述。这是将其他对照中已有门槛应用到此子集，既不是预注册RPL验收，也不是修改原来的数值复现阈值。该筛选结果不用于把严格验收改成通过。

## 当前执行方案

1. 保留原始外机失败receipt、诊断轨迹、所有未收敛结果和原容差。正式六单元严格数值复现仍未通过；已从原摘要独立重算核对。
2. 本轮外机手动操作结束，不要求用户再跑零散诊断、Windows补跑或重复挑选最接近参考值的结果。
3. 继续现有RPL十种子生产和核心四阶段审计。全部结果齐后再决定方法结论的强度；本次单种子描述性方向不能替代它们。
4. 在最终稿的复现说明与局限中准确区分：外机独立从头执行完成、两机各自可重复、跨机严格数字不匹配。当前先存证，不提前改稿。
5. 当前没有定位到某个具体算子的实现错误，故不对冻结源码进行盲目修补。需要新数值稳定训练方案时应另建版本，并验证受影响对照；原证据保持可追溯。

这套处理使研究可以继续，同时保留尚未解决的数值一致性边界。不能宣称问题已被“修好”，也不需要把已完成的全部实验推倒重算。
