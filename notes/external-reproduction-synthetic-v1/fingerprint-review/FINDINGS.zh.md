# 外部 Mac 模型指纹核查

用户确认本包来自另一台 Mac。对比同一公开入口在本机从头重训得到的 8 个阶段模型；此次只读分析，未重新拟合、求卖方响应或修改数值容差。

| 核查项 | 完全一致的模型数 |
| --- | ---: |
| 分阶段训练输入绑定 | 8/8 |
| 全评估集编码与合法状态指纹 | 8/8 |
| CatBoost 树叶数、分裂边界、叶值 | 8/8 |
| 基础树模型预测数组 | 8/8 |
| 残差网络全部参数指纹 | 0/8 |
| 最终对数报价预测数组 | 0/8 |

因此，当前证据把差异定位到“残差训练后保存的网络参数已不同”这一边界。λ=0 对照也发生差异，不能把它归因于 RPL 正则本身；基础树模型和输入不匹配也不能解释本次观察。外层第2折的最大预测差异在两个权重下均仅9.536743e-7，另6个模型为0.00151–0.01199，差异幅度高度依赖折/模型。这里的数值比较覆盖每个模型1000条×11状态；不是新增效果检验。

两边列出的5项主依赖版本以及 PyTorch 构建描述完全相同；Python小版本/解释器构建、macOS版本不同。相同构建描述不证明CPU执行路径或系统数学库相同，也不证明哪项环境差异是原因。检查点不含初始化/首个梯度/逐步优化轨迹，故不能确定第一条发生分歧的训练运算。尤其不能把差异直接宣称为随机性、浮点误差、某个系统版本或算法错误所致。

原外机6单元严格数值对照仍未通过，同机从头重训通过这一事实也不变；此次诊断不升级为外机复现通过，不修改论文。原始私有诊断ZIP完整保留在仓库之外，仅发布其哈希和聚合差异，不上传参数数组或逐条预测。
