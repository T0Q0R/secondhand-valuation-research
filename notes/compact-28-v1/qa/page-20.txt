Take n > B ≥1, a core C of size B, and public active contexts j ∈{B + 1, . . . , n}. Gaps in

missingness-alias worlds. The library includes every context-insensitive priority order and exact-
gap risk ordering, but shares one mixing vector. Each priority chooses a fixed B-subset; risk always
chooses the core.

A stronger fixed library closes the gap: one rule queries the core and each of B others replaces
one core item by the active item. Fixed weights 2/(B + 2) on the core rule and 1/(B + 2) on
each replacement yield exactly these contextual marginals.
Thus the separation concerns rule
information, not dynamic weights or the intrinsic necessity of an LP solver.
