# Complete local evidence and source replay

This is a verification protocol for the already fixed study, not a new
performance experiment or a changed success criterion. It retains the complete
972 tuning and324 ordinary-BEN matrices, all27 cases per matrix, all108 fitting
stages per matrix, all54 independently refitted ordinary-BEN deployment heads,
every preset budget and all three training seeds. No favorable cohort filter.

1. Require terminal successful full audit receipts and their matching
   statistics. The full experimental packager's existing four-folder gate
   checks the raw -> audit -> contrast chain and all captured fitting stages.
   Freeze a fresh experimental ZIP without modifying the earlier component ZIP.
2. Compile and review the complete nine-cohort manuscript/figures. Package its
   exact seven evidence maps, supplied author JSON, separately named repaired
   bibliography style, bounded displays, source/assets, scripts and dependencies
   in a fresh source ZIP. Review PDF hashes and every build input/output hash
   must match; neither the named partial preview nor archive28 is sufficient.
3. `assemble_completed_delivery.py` accepts only these two complete ZIPs,
   verifies every mapped entry before writing it, materializes regular files,
   and permits shared paths only when their SHA256 values agree. Preserve both
   manifests and a new assembly receipt in the copied root. Unmapped paths,
   duplicates, traversal, symlinks, stale overlap or incomplete scope fail.
4. From the copied `sav-val` directory, use
   `verify_development_package.py` for copied tests and exact journal rebuilding.
   Rebase the seven map paths and supplied author JSON into the copy; reproduce
   the reviewed bibliography/layout flags. All source/assets declared by the
   build are present in the new source package. Original source/data reads are
   denied. This check does not retrain the scientific matrix.
5. From that same copy, use `verify_full_extension_saved_replay.py` with the four
   matching full audit/statistics directories. Independently reconstruct public
   head inputs and sorted allocations for all1296 cells/1296000 outcome rows,
   both roles and all six budgets. Check quoted prices, replay, metrics, source
   identifiers/targets, valid report states, and exact first-batch unilateral
   regret and inflation envelopes. Require all972/324 counts and the source
   SHA256 bindings. All3 sources and9 configured cohorts remain included.

The saved-model check verifies both collection manifests and actual copied
module locations. It rejects real read probes of the original implementation
and inherited training CSV, including Python import-loader access. CatBoost,
ExtraTrees, encoder/head fitting, residual training and Adam/AdamW updates are
disabled; an actual ExtraTrees.fit rejection probe verifies the fitting guard.
These are Python IO/import guards, not operating-system sandboxing. No claim of
universal IO interception. Unexpected access or fitting fails and is retained.

The copied saved-model check intentionally does not repeat original trial
selection, OOF fitting or54 independent head refits. Their complete original
receipts remain archived and checksum-bound. It must not be described as fresh
training or a second full head-refit audit. The separate original558-cell main
study copy audit remains available and can be rerun on the assembled collection.

Current implementation status: the assembly gate rejects actual partial
archive28 and the earlier component archive; the new full saved-model program
has syntax/schema preflight only. Complete assembly and all1296-cell copy replay
must actually execute before their success is reported. At creation of this
protocol, the full324 BEN independent audit is live, with26/27 logged cases.
Nothing here resolves the failed BRC practical gate, author final approval,
applicable institutional journal ranking, public release or submission.
