# EMC-Val development gate, 2026-10-06

This independent extension does not change SAV/CDM protocols, running fits or manuscript results. The complete objective remains implemented algorithms, meaningful experiments and a finished Q3-oriented paper. This gate is not a substitute for that outcome.

## Scope and frozen choices

Sources: synthetic generator 73101 (6,000 records), inherited JUCars and MUCars **training CSVs only**. Select at most 5,000 records by outcome-independent ID hash. Divide the selected cohort by a second fixed ID hash into 50% estimator, 20% action-head, 15% calibration and remainder evaluation. Membership is identical across fitting seeds 13,42,2026. This is retrospective development on previously used records, not a fresh confirmation or certified independent vehicles. Do not read inherited validation/test CSVs. Save selected data and split assignments with hashes.

Whitelist predictors from the existing price-features contract; exclude prices, target, IDs, row indices and direct reveal aliases. Four optional fields: mileage, transmission, fuel and body condition. Fit both 10th/90th quantile CatBoost models with all 16 deletion states, weighting each record's feasible states to sum to one. Natural absence cannot be hidden or recovered. CatBoost 250 iterations, depth6, learning_rate0.05, one worker per model, no tuning. Query head: 160 iterations, depth6, MultiRMSE, one worker, using only public materialized states, before-query raw/nested endpoints and query-field identity. Targets are raw/nested signed-span shrink after replay; failures have zero shrink. One shared two-output head per source/seed.

Calibration: levels alpha0.05(primary)/0.10(secondary). Ordinary split conformal uses honest nonconformity; strategic conformal uses the maximum over all feasible deletion states. Nonconformity is max(0,l-y,y-u), scale1. Use rank ceil((n+1)(1-alpha)) on n scores plus an infinite sentinel; no silent finite replacement. Freeze q before evaluation. The action head does not use calibration records/outcomes; it learns signed-span shrink with q cancellation. Endpoint ordering of the base quantile pair uses min/max, fixed before calibration. This is a definition of the base predictor, not a repair of empty final certificates.

Methods: ordinary CP/raw interval, strategic CP/raw interval, EMC/strategic CP plus inherited intersection over all weaker reports. Price output is max(0,lower_log) transformed by expm1, even if the final double-sided certificate is empty. Empty certificates count as coverage failures and have separately recorded invalid status; no reversing endpoints or quote reset.

Profiles: honest, shared pre-audit maximum raw-lower report, and shared ID-hashed feasible deletion report. Maximum deliberate hiding is two fields for report profiles; calibration and inherited certificates still include the full four-field deletion closure. This is deliberately a shared-report diagnostic, **not** a search for each method's simultaneous market equilibrium. At the stipulated lower-quote utility, full disclosure is a weak best response for EMC, so audited hidden-profile gains must not be advertised as its equilibrium welfare gains. Positive disclosure cost or new inspection-only evidence requires a separate model and protocol.

Capacities0/0.10/0.30, batch100, one queried field/listing; at zero capacity use none, otherwise ID-hash random and learned shrink. Query eligibility is publicly missing fields. Learned scores<=0 are not queried. Failed queries spend a slot. Query heads never receive original missingness type, hidden values, feasible-state indicators or labels at execution. Replay alone uses recorded values. Hash priority is public and fixed, not hidden deterrence randomness.

Total full matrix: 3 sources x3 fitting seeds x2 levels x3 methods x3 profiles x5 capacity/policy combinations = **810 cells**. Smoke is separately marked and does not count as completion. Case completion receipts permit explicit resume of terminal execution only; never launch duplicate live runs.

## Evidence and decision

Save models, split inputs/assignments, q ranks/scores, all pre-query interval states, head predictions, reports/final states/query actions, per-record coverage/width/error/bias and cell summaries. Verify every batch's hard budget and failed replay transition. Independent arithmetic audit must reconstruct both calibration order statistics, inherited endpoints and actual allocations from saved public scores, without trusting summary means. Retain all methods, levels, sources, seeds and negative outcomes.

Primary evidence: 95% joint-state coverage and actual final coverage, nonempty interval log-width, invalid certificate rate; lower-quote signed error/MAE/underpricing/overpricing; query success/failure and span reduction on common profiles. Do not compare point-estimator inflation alone to declare conservative quotes superior. Marginal population coverage follows existing strategic CP under exchangeable calibration/test records and a fixed model/transformation family; this finite retrospective data does not verify those assumptions or provide group/market-wide coverage guarantees.

Gate for further method development: all observed nesting and EMC lower-quote monotonicity checks pass; EMC final coverage on each source is consistent with nominal coverage within a 95% Wilson sampling interval (a descriptive diagnostic, not a new theorem or multiple-comparison-adjusted test); on primary shared hiding profiles, learned acquisition reduces log-width relative to random at equal hard caps without increasing invalid-certificate rate. Source-level intervals must average paired fitting-seed effects before resampling common batches. If learned acquisition does not improve width, if lower quotes become unhelpfully low, or if nearest work already supplies the same joint design, do not claim a successful innovative method. No threshold or missing group may be selected after observing results.

Novelty remains unresolved. Strategic CP and generic disclosure closure are established. The current experiments can reject a weak composition; favorable results alone do not prove algorithmic novelty or Q3 venue suitability.
