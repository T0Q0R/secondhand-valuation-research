# 一次运行完成残差差异诊断

此入口取代前面分散执行的小诊断。外机只需运行一次、回传一个ZIP；程序不会自动把不匹配改成通过，不改变原论文结果或验收标准。

## 另一台 Mac 执行

在原复现仓库目录执行：

```sh
cd ~/Desktop/secondhand-reproduction/sav-val
git pull --ff-only
../.venv-gdfs/bin/python reproduction/macos-core-v2/run_onepass_diagnostic.py --run ../external-rpl-synthetic
```

最后会打印 `ONEPASS_RETURN_ZIP` 和路径。把那一个 `external-rpl-onepass-return-时间戳.zip` 发回即可；如果报错，也回传这个包，不重复手动尝试不同设置。

程序依次完成四次独立子进程运行：双线程两次、单线程两次。每次复用全部8个已核验基础模型，重置残差网络，调用原冻结训练函数完成两轮各6个epoch，保留seed13/14的重置、原数据划分与损失设置。采集头不参与原价格网络训练，因而无需重训基础模型或采集头。

诊断覆盖每批的初始化、反向传播前、梯度裁剪前后和参数更新；前3批保留详细数值，其余批次保留指纹。程序自动比较同线程重复结果、单/双线程结果以及各自原检查点，检查跟踪器是否改变拟合，核验原模型文件哈希未变。结束后还需要两台机器间的轨迹比较，不能把本机重复一致当成跨机复现通过。

本机完整自检约129.82秒，回传包约53.1MiB；外机速度尚未测量，下载/上传时间另计。运行按顺序执行，最多2条计算线程。请接电、保持终端打开并避免休眠。进度逐模型打印，日志和阶段结果持久保留。不会安装/更新依赖、改系统设置、覆盖原模型、修改容差或写论文。

## 中断与失败

正常阶段会保存独立ZIP。需要恢复时，把上次的工作目录通过`--work <原工作目录>`传回，程序仅复用源码、Python/系统与输入绑定相符的完整阶段；输出仍使用一个新ZIP。不要同时启动两个诊断。强制关闭后若留下`.run.lock`，先确认原进程退出再移除旧锁。

## Windows

Windows核心训练已完成且保存了模型时，在Windows仓库根目录执行：

```powershell
..\.venv-gdfs\Scripts\python.exe reproduction\macos-core-v2\run_onepass_diagnostic.py --run ..\external-rpl-windows-synthetic
```

不必为了诊断在Windows重新做一遍已经完成的Mac训练；使用现有可用的外机即可。脚本支持两种已声明的合同，不导入Unix专属文件锁；Windows实机执行尚待验证。
