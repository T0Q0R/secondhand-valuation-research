\section{Data and Code Availability: Development Status}
The reused public inputs are JUCars-2024 version 2 and MUCars-2024 version 2,
available at their versioned dataset DOIs~\cite{thalji2026jucars,tabarnoust2024mucars}
under CC BY 4.0. Synthetic records are generated by the supplied
\texttt{simulate\_market} implementation with seeds and caps in the experiment
configuration. Source-manifest builders and
\texttt{rebuild\_source\_splits.py} reconstruct the processed training and
validation inputs from checksum-bound raw files. Historical source-test
labels are not inputs to the current experiment runners.

The local development source archive contains implementations, configurations,
input receipts, independent auditors, behavior tests and manuscript sources.
Dependencies and fresh-output commands are recorded in
\texttt{requirements-lock.txt} and \texttt{REPRODUCING.md}. The complete fitted
models, per-listing outcomes, calibration matrices, query allocations and
analysis collections are retained in local study directories; they are not
included in that lightweight archive. No public repository identifier or
software-release licence has been assigned to the new code and outcomes.
The final availability statement must match the completed, actually attached
or deposited evidence collection.

A separate local completed-component archive contains the named finished
studies' saved models, per-listing outcomes, calibration and analysis files,
plus the four checksum-bound processed training/validation inputs. Its
manifest records every file and materializes the nine CDM source/seed links.
The earlier completed-component archive excludes the size/tuning and
ordinary-benefit allowance extensions. A new local completed-experimental
evidence archive includes both full independently audited matrices, saved
models and paired statistics, alongside all previously completed components:
17,343 manifest-bound files and the four processed inputs, with 6,600
materialized links. The local source and experimental collections pass an initial combined copied
reproduction check over 17,637 distinct files. The copy passes 49 behavior
tests, reconstructs 18 manuscript source/assets exactly, replays all 1,296
extension deployment cells and 1,296,000 outcomes with fitting disabled,
and reaudits 558 original main arithmetic cells. Six complete figure images
and 162 plotted rows are identical. Original-source/data IO rejection probes
pass; these Python guards are not an operating-system sandbox. This saved
evidence replay does not repeat the original full training/OOF/head-refit
audits or supply prospective market evidence. Neither collection is a
public deposit.
